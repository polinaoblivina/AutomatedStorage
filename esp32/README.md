# Прошивка контроллера ESP32

Считывает RFID-карту, открывает замок ячейки, взвешивает её до и после и отправляет результат на сервер.

## Настройка

1. Скопируйте `config.cpp.example` в `config.cpp`.
2. Укажите в `config.cpp` Wi-Fi, адрес сервера (`http://<IP>:5037`, без пути), ключ устройства
   (должен совпадать с разделом `Devices` в настройках сервера) и id ячеек для весов (`CELL_IDS`, из `GET /api/cabinets`).


`config.cpp` содержит пароли и не попадает в git.

## Библиотеки

Устанавливаются через Arduino Library Manager:

- Adafruit GFX Library
- Adafruit BusIO
- Adafruit SSD1306
- U8g2_for_Adafruit_GFX
- ArduinoJson 7.4.3
- MFRC522 (miguelbalboa/rfid)
- HX711 (bogde/HX711)

## Подключение

Пины задаются в `config.h`:

| Устройство | Пины |
|---|---|
| OLED SSD1306 | SDA 16, SCL 17 |
| RFID RC522 | SS 21, RST 22, SPI 18/19/23 |
| HX711 №1 | DT 13, SCK 14 |
| HX711 №2 | DT 35 (+ 10 кОм к 3.3 В), SCK 33 |
| Реле замка | 27 |
| Датчик двери (геркон MC-38) | 12 и GND (без резистора, внутренняя подтяжка) |
| Светодиоды | Wi-Fi 25, RFID 26, весы 1 — 32, весы 2 — 15, реле — 2, ошибка — 4 |

HX711 питать от 3.3 В. Светодиоды — через резистор 220–330 Ом на GND.
Второй провод геркона — только на GND: GPIO12 при включении должен быть в LOW.

## Весы

`SCALE_COUNT` в `config.h` — количество весов. Для каждых весов в `config.cpp` задаётся id ячейки (`CELL_IDS`);
пустая строка — весы не используются. Коэффициенты калибровки — `SCALE_1_FACTOR`, `SCALE_2_FACTOR`
(вес на экране при коэффициенте 1.0, делённый на массу эталонного груза в граммах).

## Как заканчивается сессия

Карта → замок открыт, пока дверь не откроют (не дольше 3 с) → сотрудник закрыл дверь → когда все весы 2 с не
меняются больше чем на 2 г, снимается вес «после». Если дверь не открыли за 5 с — сессия заканчивается. Если дверь
открыта дольше минуты — на экране «ЗАКРОЙТЕ ДВЕРЬ!» и мигает светодиод ошибки; через 2 минуты сессия закрывается
сама. Без датчика (`DOOR_SENSOR_ENABLED 0`) сессия длится не меньше 15 с и заканчивается, когда весы успокоились.
Если на экране «Откройте дверь» при открытой двери — поменяйте `DOOR_CLOSED_LEVEL` на `HIGH`.

## Сессии и работа без сети

После сессии шкаф отправляет все ячейки одним запросом `POST /api/device/sessions`. Если сеть или сервер
недоступны, сессия остаётся в очереди в памяти (до 10 штук, на экране — «Не отправлено: N») и досылается
каждые 15 с. Каждая сессия имеет случайный id, поэтому повторная отправка не задваивает операции; время
операции в журнале — время сессии, а не отправки. При выключении питания очередь теряется.
